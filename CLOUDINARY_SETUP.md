# Cloudinary Configuration for Railway

# Add these to your Railway environment variables:

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key  
CLOUDINARY_API_SECRET=your_api_secret

# How to get these values:
# 1. Go to https://cloudinary.com/users/register/free
# 2. Create a free account (52GB storage, 25 credits/month)
# 3. Go to Dashboard > Settings > API Keys
# 4. Copy the Cloud Name, API Key, and API Secret
# 5. Add them to Railway environment variables

# In Railway:
# 1. Go to your project dashboard
# 2. Click on your service
# 3. Go to Variables tab
# 4. Add the three variables above
